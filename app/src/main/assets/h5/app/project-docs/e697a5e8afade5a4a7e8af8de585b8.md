## 三、产品简介

与其他日语学习软件相比，本应用具有3大特色： ①辽宁人民出版社携手海笛出品（著名品牌品质有保障）； ②独有的以2部权威词典为基础（《新日汉辞典》和《新汉日辞典》)； ③内容丰富功能全面，可查单词、查日语例句，还能背单词等。 【依托权威专业词典】 融合由辽宁人民出版社出版的权威日语词典——《新日汉辞典》和《新汉日辞典》，有着很高的科学性和实用性。 【收词全面领域广泛】 词库规模宏大，共收录《新日汉辞典》7.5万词目、《新汉日辞典》所有词目。 【原汁原味地道发音】 单词、例句提供发音，让你感受原汁原味的日语、学会地道口语。 【单词背诵】 个性化定制生词背诵计划，AI根据艾宾浩斯记忆曲线智能提醒复习，轻松记住单词。 【粘贴板快速查词】 在设置中打开粘贴板查词功能，将文字复制到应用内的粘贴板中，即可点击文字快速查词。 【通知栏快捷查词】 学习时不方便打开词典查词？打开通知栏快捷查词功能，即可轻松查询生词。 由海笛携手辽宁人民出版社官方正版发布，日语大词典App提供方便快捷的查词服务和实用强大的学习服务，击破日语单词学习难点，让你事半功倍地学好日语。 选择正版应用，学习更有保障！
