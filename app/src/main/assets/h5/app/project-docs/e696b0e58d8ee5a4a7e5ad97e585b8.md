## 三、产品简介

内涵宏富、图文辉映，唯一正版《新华大字典》App综合版，由商务印书馆国际有限公司授权发行，融合13部权威字典、词典，可一站式查学字/词/成语/古汉语/诗词。 【融合13部权威字典、词典】 除《新华大字典》、《现代汉语词典》、《古代汉语词典》、《成语大词典》等权威词典之外，额外收录《小学生字典》、《小学生词典》、《小学生成语词典》等，共融合13部权威字典、词典。 【标准发音与笔顺】 提供词条的发音与汉字的标准笔顺动画，学标准汉字发音、写标准汉字、说标准普通话。 【图文并茂】 配有1500余幅插图，内容涉及古代文物、历代名画等，具有丰富的历史文化内涵。 【特色古汉语专栏】 提供古代汉语语法、古代汉语虚词等栏目，引入《论语》、《诗经》、《说文解字》等20余部经典古籍中的例证，深度解析古汉语字词。 【中小学同步学】 针对小学、初中、高中人群提供针对性的教材同步学、必备成语、古诗词栏目，省时省力、学习更高效。 【每日一学】 每日5分钟、厚积薄发，提供每日一字、每日一词、每日成语、每日一首诗等共9个每日学习栏目，识新词、读成语、学辨析、背古诗、会表达。 选择正版应用，学习更有保障！
