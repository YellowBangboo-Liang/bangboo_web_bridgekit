## 三、产品简介

与其他法语学习软件相比，本应用具有四大特色： ①外研社携手海笛出品，有品质保障； ②独有的以6部权威词典为基础：《新世纪法汉大词典》等； ③与法语教材/教学相结合； ④内容和功能丰富全面，可查单词、动词变位、例句，还能背单词、学语法、练听力、练口语等。 【法语教材配套资源】 ①学习栏目内含以下图书配套音频资源：“新经典法语”系列、“你好！法语”系列、法语专四专八考试样题集。 ②创新《大家的法语》系列互动数字教材，配套音视频资源带你轻松入门法语，零基础也可沉浸式畅学。 【收词全面领域广泛】 所收录的词典皆为知名词典专家历时十余载编纂而成，覆盖常见词汇、商务词汇、行业词汇，法汉收词12万余条、汉法收词10万余条。 【畅学法语相关专栏】 动词变位太难记？汇总整理动词变位表、常用动词搭配表、常用符号表，想查就查。 法语语法太难学？特邀名师录制语法、语音课程，词汇发音、搭配、句式一网打尽。 【专注强化听力口语】 听写训练：分单元进行法语听力训练，循序渐进提高法语听力。 口语训练：涵盖日常生活社交中的各类常见话题，为学习者提供地道的口语发音指导和录音自查功能。 版权所有，盗版必究！
