## 三、产品简介

外教社词博士APP由上海外语教育出版社与上海海笛数字出版科技有限公司联合出品，面向在校大学生及从事翻译行业人士，以英语词汇学习为切入点、以优质语料为内容支撑，为用户提供词汇学习与词典查询一站式服务。 【权威词典】 内置《新牛津英汉双解大词典》（第2版）、《外教社大学英语词典》、《外教社综合英汉大词典》等权威词典，满足你的日常查词需求。 【专业词汇】 分册收录80个专业/学科的基础词汇（如：船舶、航空航天、医学、计算机、信息技术、经济学等），助你在短时间内快速学习专业英语词汇，为你阅读专业文献、从事专业英语翻译和交流等打下坚实基础。 【教材词汇】 分册、分单元收录外教社大学英语教材主干教程中的课后生词，助你与课堂教学同步学习。 【课文原句】 本应用内置外教社大学英语教材主干教程语料库，查询生词时可轻松阅览对应课文原句。 【海量例句】 内置大规模英汉对照语料库，助你拓展语境、深入了解词汇意义。 【地道发音】 单词、例句均提供发音，助你学会地道口语。 【背单词】 个性化定制背诵计划，APP根据艾宾浩斯记忆曲线智能提醒复习。 选择正版应用，学习更有保障！
